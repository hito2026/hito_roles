# Hito Roles

Organigrama interactivo de Hitofusion, realizado a partir de los perfiles documentales compartidos.

- 18 perfiles documentados y dos puestos futuros diferenciados.
- Comentarios literales de Alejandro Sartorio en los perfiles correspondientes.
- Propuesta de Infraestructura / DevOps en rojo, sin dependencia jerárquica asignada.
- Dos conexiones de colaboración propuestas según los comentarios de Alejandro.
- Panel de evidencias documentales con citas y enlaces de origen.

## Publicación

GitHub Pages sirve `index.html` desde la raíz de la rama principal. El archivo es autocontenido y no requiere dependencias externas.

Los archivos Word originales y las credenciales no forman parte de este repositorio.
